# 📚 Sistema de Gerenciamento de Biblioteca

Sistema Full Stack desenvolvido para estudo de **React** e **C#**, simulando o gerenciamento de uma biblioteca com cadastro de livros, usuários e controle de empréstimos.

## 🚀 Objetivo

Este projeto foi criado com fins educacionais para praticar o desenvolvimento de aplicações modernas utilizando **React + TypeScript** no frontend e **ASP.NET Core Web API** no backend, com integração ao **PostgreSQL**.

## 🛠️ Tecnologias

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL

### Ferramentas
- Git & GitHub
- Visual Studio 2022
- VS Code

## ✨ Funcionalidades

- 📖 Cadastro de livros
- ✏️ Edição e exclusão de livros
- 👤 Gerenciamento de usuários
- 🔄 Controle de empréstimos e devoluções
- 🔍 Pesquisa de livros
- 📱 Interface responsiva

## ⚙️ Executando o projeto

### Clone o repositório

```bash
git clone https://github.com/seu-usuario/sistema-de-gerenciamento-de-biblioteca.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
dotnet restore
dotnet run
```
